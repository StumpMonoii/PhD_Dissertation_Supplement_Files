This repository contains data, tables, and R code used to analyze red oak-insect interactions in the upper and lower peninsulas of Michigan. 
Mono-ii is a sumo term for when the result of a match is questioned (always question your data). 

**Data: **
  Bi-weekly data and R Studio code: data from 2023-2025 from a common garden experiment in the upper peninsula of Michigan at the Ford Center in Alberta, Michigan. 
    **Items available: **
    RStudio code ("Bi-weekly R Code") 
    All data in Excel from 2023-2025 ("F_ALL")
    Truncated herbivory data in Excel from 2023-2025 ("F_ALL_HERB")
    Truncated lesion data in Excel from 2023-2025 ("F_ALL_LES"
