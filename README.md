This repository contains data, tables, and R code used to analyze red oak-insect interactions in the upper and lower peninsulas of Michigan. 

  Bi-weekly data from 2023-2025 from a common garden experiment in the upper peninsula of Michigan at the Ford Center in Alberta, Michigan: 
    
    1. R code ("#Red oak Ford Center data, Bi-weekly R code 2023-2025") 
    
     2. All data in Excel from 2023-2025 ("F_Herb-Les")
    
      3. Truncated herbivory and lesion data in Excel from 2023-2025 with common garden block location for heat maps ("plot-map-d")
  
Yearly data from 2019-2025 for upper and lower peninsula of Michigan locations: 
  1. Weather data and graphs for the Upper Peninsula Ford Center and Forest (from 1958-2025) and the Lower Peninsula Kellogg Experimental Forest (from 1949-2025)
